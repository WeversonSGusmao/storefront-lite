# 🛒 Storefront Lite

Uma aplicação front‑end simples e funcional que simula um catálogo de produtos com **busca**, **filtros**, **ordenação**, **carrinho persistente** e **checkout via WhatsApp** — tudo feito com **HTML, CSS e JavaScript puro**, sem frameworks.

🔗 **Demonstração online:**  
https://weversonsgusmao.github.io/storefront-lite/

---

## 📦 Recursos

- Catálogo dinâmico carregado via JSON  
- Busca instantânea  
- Filtros automáticos por categoria  
- Ordenação por nome e preço  
- Carrinho persistente com `localStorage`  
- Subtotal calculado em tempo real  
- Finalização via WhatsApp  
- Tema claro/escuro com toggle  
- Layout responsivo (mobile-first)
